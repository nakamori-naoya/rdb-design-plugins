# ユーザータイムラインのクエリデータモデル

利用者が自分または他者のユーザータイムラインを見る読み取りが、ポストの業務とアカウントの業務のコマンドデータモデルが残すデータだけで実現できることを確かめる。対象利用者がいるかを`users`で確かめ、`posts`から対象利用者が投稿者であるポストをすべて選び、`post_id`の大きい順に並べ、ポストした日時を`post_base_events`の`created`の行から結び付ければ、業務知識が決めた表示対象と並び順どおりに返せる。新しいテーブルや列は要らない。

## ポストと、ポストした時点と、利用者がいるかだけを読む

| 読むテーブル | 持ち主の資料 |
|---|---|
| `users` | [アカウントのコマンドデータモデル](../アカウント/command-data-model.md) |
| `posts` | [ポストのコマンドデータモデル](../ポスト/command-data-model.md) |
| `post_base_events` | [ポストのコマンドデータモデル](../ポスト/command-data-model.md) |

### ユーザータイムラインを見る

まず`users`に、対象利用者の利用者IDと同じ`user_id`の行があるかを確かめる。無ければ、対象利用者がいないという結果を返し、ポストは読まない。行があれば、`posts`から`author_user_id`が対象利用者の`user_id`である行をすべて選ぶ。件数やポストした日時で選ぶ行を狭めない。見る人が誰か、見る人が対象利用者をフォローしているかは、選ぶ行を変えない。選んだ行を`post_id`の降順に並べる。これが業務知識の新しい順である。ポストした日時は`posts`に無いので、`post_base_events`の`event_type`が`created`の行を`post_id`で結び付け、その`occurred_at`を使う。ポストした日時は返すだけで、並びには使わない。返すのは、ポストID（`post_id`）、投稿者（`author_user_id`）、本文（`body`）、ポストした日時である。

一回に返す件数の上限（50件）と、続きを読むための位置の指定は、業務知識が API の契約に置いた値である。続きを読むときは、指定された位置のポストIDより小さい`post_id`の行だけを、同じ並びで返す。境界の例（BDD-005）は、この API の契約の値を前提に書いた。

## 業務知識のBDDとの対応

| 業務知識のBDD | この資料のBDD |
|---|---|
| BDD-001 | BDD-001 |
| BDD-002 | BDD-002 |
| BDD-003 | BDD-003 |
| BDD-004 | BDD-004、BDD-005 |
| BDD-005 | BDD-006 |
| BDD-006 | 対象外 |
| BDD-007 | BDD-007 |

利用者登録を済ませていない人が見ようとする場面（業務知識の BDD-006）は、見る人が利用者かどうかの確認で拒まれ、ユーザータイムラインのデータを読むところまで届かないので対象外にした。

## 未決

一件ごとにポストした日時を返すことは、業務知識で仮に置いた見せる項目に従った。業務知識の未決が解け、ポストした日時を見せないと決まれば、`post_base_events`は読むテーブルから外れる。表示対象と並び順は変わらない。

## BDD

ポストIDは、番号の大きいほうが大きい`post_id`を表す。

### [BDD-001] フォローしていない他者のユーザータイムラインは、その人のポストだけが新しい順に返る

```gherkin
Given: 利用者 U-0001 と利用者 U-0002 と利用者 U-0003 は利用者登録を済ませており、利用者 U-0001 は利用者 U-0002 をフォローしていない
  And: 利用者 U-0002 はポスト P-0001 を2026年10月1日 09:00に、ポスト P-0003 を同じ日の10:00にした
  And: 利用者 U-0003 はポスト P-0002 を2026年10月1日 09:30にした
When: 利用者 U-0001 が2026年10月1日 11:00に利用者 U-0002 のユーザータイムラインを見る
Then: ポスト P-0003、ポスト P-0001 の順に、投稿者、本文、ポストした日時と一緒に返る
  And: 利用者 U-0003 のポスト P-0002 は返らない
```

#### データの状態

**Before**

**`users`**

| user_id |
|---|
| U-0001 |
| U-0002 |
| U-0003 |

**`posts`**

| post_id | author_user_id | body |
|---|---|---|
| P-0001 | U-0002 | おはようございます |
| P-0002 | U-0003 | 今日は雨です |
| P-0003 | U-0002 | 昼ごはんを食べました |

**`post_base_events`**

| post_id | event_type | occurred_at |
|---|---|---|
| P-0001 | created | 2026年10月1日 09:00 |
| P-0002 | created | 2026年10月1日 09:30 |
| P-0003 | created | 2026年10月1日 10:00 |

**取得結果**

| ポストID | 投稿者 | 本文 | ポストした日時 |
|---|---|---|---|
| P-0003 | U-0002 | 昼ごはんを食べました | 2026年10月1日 10:00 |
| P-0001 | U-0002 | おはようございます | 2026年10月1日 09:00 |
