# フォローのクエリデータモデル

利用者がフォローする相手を探す読み取りで、登録済みの利用者それぞれが本人か、フォロー中か、フォローしていないかを知るには、アカウントのコマンドデータモデルの利用者と、フォローのコマンドデータモデルのフォローのいまの状態を組み合わせれば足りることを確かめる。新しいテーブルや列は要らない。フォローに起きたことの列（`follow_base_events`）は読まず、`follows`の`status`だけで区別が決まる。

## 利用者の一覧に、探した本人からのフォローの状態を重ねる

| 読むテーブル | 持ち主の資料 |
|---|---|
| `users` | [アカウントのコマンドデータモデル](../アカウント/command-data-model.md) |
| `follows` | [フォローのコマンドデータモデル](command-data-model.md) |

### フォローする相手を探す

`users`の行をすべて選ぶ。業務知識は非公開アカウントやブロックで外す利用者を置いていないので、ここで外れる行は無く、探した本人の行も含まれる。それぞれの利用者について、`user_id`が探した本人と同じなら本人とする。そうでなければ、`follows`から`follower_user_id`が探した本人で`followee_user_id`がその利用者の行を結び付け、その`status`が`following`ならフォロー中、行が無いか`not_following`ならフォローしていない、とする。ほかの利用者を`follower_user_id`に持つ`follows`の行は、探した本人から見た区別に使わない。返すのは、利用者IDと、本人・フォロー中・フォローしていないの区別である。

並びと一回に返す件数は、業務知識がどの利用者を表示するかを変えない値として API の契約に置いたので、この資料では判断に使わない。取得結果の表は、API の契約の利用者IDの順を前提に並べた。

## 業務知識のBDDとの対応

| 業務知識のBDD | この資料のBDD |
|---|---|
| BDD-017 | BDD-001 |

業務知識のクエリのBDDは一件で、対象外にしたものは無い。登録済みの利用者が探した本人だけのときの境界は、業務知識にBDDが無いが、本人の行が必ず返ることを示すためにこの資料のBDD-002として足した。

## 未決

一回に返す件数と続きの読み方は、業務知識が API の契約に置いたが、要件に値が無い。続きの境目の例は、値が決まってから同じ入口で足す。確かめる相手は、要件を決めた利用者である。

## BDD

### [BDD-001] 登録済みの利用者すべてが、探した本人から見た区別と一緒に返る

```gherkin
Given: 登録済みの利用者は U-0001、U-0002、U-0003、U-0004、U-0005 の5人である
  And: 利用者 U-0001 は2026年10月1日 10:00に利用者 U-0002 をフォローし、いまもフォロー中である
  And: 利用者 U-0001 は2026年10月1日 11:00に利用者 U-0003 をフォローし、2026年10月2日 10:00に外した
  And: 利用者 U-0004 は利用者 U-0001 をフォロー中で、利用者 U-0001 は利用者 U-0004 をフォローしたことが無い
  And: 利用者 U-0002 は利用者 U-0005 をフォロー中で、利用者 U-0001 と利用者 U-0005 の間にはフォローが一度も無い
When: 利用者 U-0001 がフォローする相手を探す
Then: U-0001 は本人、U-0002 はフォロー中、U-0003、U-0004、U-0005 はフォローしていない、として5人全員が返る
```

#### データの状態

**Before**

**`users`**

| user_id |
|---|
| U-0001 |
| U-0002 |
| U-0003 |
| U-0004 |
| U-0005 |

**`follows`**

| follow_id | follower_user_id | followee_user_id | status |
|---|---|---|---|
| F-001 | U-0001 | U-0002 | following |
| F-002 | U-0001 | U-0003 | not_following |
| F-003 | U-0004 | U-0001 | following |
| F-004 | U-0002 | U-0005 | following |

**取得結果**

| 利用者ID | 区別 |
|---|---|
| U-0001 | 本人 |
| U-0002 | フォロー中 |
| U-0003 | フォローしていない |
| U-0004 | フォローしていない |
| U-0005 | フォローしていない |
